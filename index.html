DTI Price Monitoring System (Region IX)

A secure, centralized, and automated web-based system to streamline the collection, processing, reporting, and analysis of commodity prices.

PHP MySQL Bootstrap 5 Excel Extraction Engine

Project Context & Objectives

The Department of Trade and Industry (DTI) is mandated to ensure the availability of Basic Necessities (BN) and Prime Commodities (PC) at reasonable prices. This project transitions DTI Region IX from a tedious, manual data consolidation workflow to a digitized, centralized system.

  • Automated Extraction & Processing: Eliminates manual data entry by extracting thousands of price records from uploaded Excel spreadsheets and automatically calculating "Lowest" and "Highest" price ranges.
  • Dynamic Reporting: Generates standardized Provincial and Regional Price Summary Reports in Excel format for quick compliance checking.
  • Centralized Masterlist & Analytics: Maintains an updatable product catalog with a strict audit trail (Movement Log) for SRP adjustments, and provides interactive visual analytics for price trends over time.

Scope & Limitations

The system is specifically tailored for a System Administrator acting as the centralized data manager, eliminating the need for advanced technical database skills.

  • Geographical Scope: Exclusively handles data for Region IX provinces (Zamboanga City, Zamboanga Sibugay, Isabela City, Zamboanga Del Sur, Zamboanga Del Norte).
  • Limitations: As an internal administrative tool, it features a single-user architecture without a consumer-facing public portal, direct POS API integrations, or a native mobile application.
