Week 3: Frontend UI, Local Database Setup, and File Upload Logic

This week focused on developing the web-based price reporting system, polishing the UI, designing database tables on localhost, and building backend logic using a Composer spreadsheet library to extract data from uploaded Excel files.

I finalized the frontend UI and the SRP menu layout, and completed the database structure on localhost. A significant challenge was figuring out how to smoothly extract data from Excel files and map it to the database, which I solved by researching and implementing a Composer package. I achieved a 65% working file upload system where data is accurately extracted and inserted without errors.

Key Tasks Accomplished

  • Polished UI and added a functional SRP menu.
  • Designed and created database tables in localhost.
  • Built backend logic for file uploads.
  • Integrated Composer spreadsheet library to read Excel files and save data to the database.
