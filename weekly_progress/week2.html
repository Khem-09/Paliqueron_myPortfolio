Week 2: System Refinement, UI Development, and Database Architecture

This week focused on pivoting the project’s scope based on supervisor feedback, transitioning from a general reporting tool to a specialized "Price Monitoring System." My work centered on front-end development and designing a robust database architecture to handle real-world DTI data.

During a consultation with my Division Supervisor, we refined the project goals to focus on a system that tracks the lowest and highest prices per SKU, monitors regional trends, and generates visual graphs. I spent the week mapping the entire system workflow—from the initial Excel file upload to the final report generation. I successfully designed and coded the front-end interfaces for the Dashboard, Provincial Reports, Regional Summary, and Price Trends pages using HTML, CSS, and Bootstrap.

A major technical challenge I addressed was architectural: the source Excel files organize data horizontally, which is inefficient for databases. To resolve this, I researched and applied Third Normal Form (3NF) principles to create a Logical Data Model and ERD that separates product/store details from weekly price logs. This ensures the system remains fast and prevents data duplication. I also gained professional insights into how DTI classifies Basic Necessities (BN) and Prime Commodities (PC).

Key Tasks Accomplished

  • Refined project scope to a "Price Monitoring System" focused on SKU-level tracking and price trends.
  • Designed and wrote the front-end code for the Dashboard, Provincial, and Regional report screens.
  • Mapped the end-to-end system workflow from Excel ingestion to data visualization.
  • Developed the Entity-Relationship Diagram (ERD) and Logical Data Model for the MySQL database.
  • Applied 3NF normalization to restructure horizontal Excel data into a vertical database format.
