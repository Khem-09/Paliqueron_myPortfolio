Week 7: Full-Stack Integration and Database Optimization

My primary responsibility was full-stack development to build out the main user interfaces and backend logic for the Dashboard, Price Trends visualization, and Product/SRP management modules.

I successfully completed the three main parts of the system, making them ready for use. A major challenge was severe system lag caused by loading too many products from the database on the Product and SRP page. I engineered a workaround by restructuring the data retrieval process, implementing server-side data pagination with "Previous" and "Next" controls, significantly improving loading speeds.

Key Tasks Accomplished

  • Developed the main system Dashboard and Price Trends visualization module.
  • Built the Product and SRP management interface.
  • Wrote backend logic connecting the modules to the database.
  • Restructured data retrieval and implemented pagination controls (Prev/Next) to resolve slow load times.
