Week 4: Backend File Uploading and Database Normalization

My primary focus was implementing the backend logic to handle bulk uploading of Excel files containing provincial pricing data. I also identified structural inefficiencies and applied database normalization principles to optimize data storage.

I deployed the backend file-upload module, achieving an 85% accuracy rate in automated data extraction. I faced challenges mapping parsed data due to file variability, which I resolved by designing a rigid, standardized Excel template. Furthermore, I refactored the database schema by extracting specifications into a new product variants table, improving structural integrity and scalability.

Key Tasks Accomplished

  • Developed backend functionality for bulk Excel file uploads.
  • Programmed extraction of key data points (commodity, brand, SRP, store prices).
  • Standardized Excel file templates to minimize extraction errors.
  • Applied database normalization by creating a product variants table.
